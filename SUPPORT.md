# Support

- **Questions and ideas:** open a [discussion](https://github.com/priemskiyyy/frame/discussions) or an issue.
- **Bugs:** open an [issue](https://github.com/priemskiyyy/frame/issues) with the versions of Frame, your adapter and its SDK, the platform, and the smallest code that shows the problem. An outcome and its `request.id`, and the diagnostics events around it, help most. Diagnostics never carry a value you published.
- **Security:** see [SECURITY.md](SECURITY.md). Please do not file vulnerabilities as issues.

Which SDK versions an adapter supports, and what has and has not run on a device, is in each adapter's README and in [limitations](docs/limitations.md).
